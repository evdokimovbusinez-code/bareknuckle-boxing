# Bare-Knuckle Boxing — instructions for Claude

Browser boxing game on three.js 0.160 (+ cannon-es), single page. UI text is in Russian; keep it Russian.

## Build rule (important)
- **Never edit `index.html` by hand.** It is generated. Edit files in `src/`, then run `bash tools/check.sh`
  (rebuilds `index.html` via `python3 src/assemble.py` and syntax-checks the module). Commit both `src/` and the rebuilt `index.html`.
- `src/assemble.py` builds ONE ES module from: `src/g_a.js` (imports, renderer, lights) + blocks spliced by line range from
  `src/boxer.html` (ring/arena, post-processing, asset list, cloth, hair, shorts) + `src/g_pre.js` (skin/blood/sweat shader chunks)
  + all `src/game/NN_*.js` concatenated **in name order** (they share one scope — no imports between them) + markup/CSS `src/g_head.html`.
  Do not change line numbers in `src/boxer.html` (assemble.py depends on them). New game code goes into a new `src/game/NN_name.js`
  placed in the right order (things it uses must be defined earlier or be hoisted functions).
- `src/bench.js` / `src/dbg_extra.js` only go into the debug build `gtest.html` (git-ignored).
- Balance bench (R-02): `bash tools/shot.sh /tmp/b.csv balance [-p masher,jabspam,turtle,mover] [-d easy,normal,hard] [-n 30]`
  (`tools/test/balance.py`: parallel pages, CSV + policy × difficulty table). In the page: `__bot.run(policy, diff, n, o)` (bots drive P1
  through `press` / `setBlock` / `P1.moveDir`, nothing drawn, cutscenes skipped), `__bot.prof()` = ms per step of `frame()`.
  Baseline of `main`: `docs/balance/`. Any change to the AI / damage / stamina: rerun it and put before/after in the PR.

## Assets (issue #43)
- First load: `assets/pack.glb` (3.35 MB) + 13 `.webp` (2.46 MB) instead of 9 `.fbx.txt` + 13 `.jpg` (20.9 MB).
  The GLB keeps the **exact** FBX byte streams (zlib per bufferView) plus `face.bin` — the game still parses them with
  `FBXLoader`, so `skinTemplate`, bone names, bind matrices and face morphs are byte-for-byte the same. Only the 300 unused
  Shape geometry bodies are stripped; their 32 kept `FACE_SHAPES` deltas live in `face.bin` (`faceShapesPacked()` in `03b_face_shapes.js`).
- **Rebuild the pack from the original `.fbx.txt` / `.jpg`:**
  `python3 tools/assets/convert.py` — needs Blender's `bpy` (WebP encoder). It reads `assets/`, writes `assets/pack.glb`
  and the 13 `.webp`, prints the before/after size table. There is no other build step and no npm/gltf-transform step.
- The old `.fbx.txt` / `.jpg` files are kept: if `pack.glb` is missing or broken, `loadPack()` (`src/assemble.py`) silently
  falls back to them and `T.fm` is built by `faceShapes()` instead of `faceShapesPacked()`. KTX2 was not used — no
  toktx/basisu encoder in this environment, WebP is the allowed fallback.

## Looking at the game (do this for every visual change)
- `bash tools/shot.sh /tmp/shots/a.jpg fight 4` — quick fight, 4 s in. `... menu` — the menu. `... js "CODE"` — run CODE first
  (`window.__g` exposes `G, P1, P2, camera, scene, ARENA, ...`; `__tick(n, dt)` steps the sim, e.g. `__tick(300, 1/60)`).
  Close-ups: pin the camera with `window.__camHold = { p: [x, y, z], l: [x, y, z] }` (world metres; fighters face each other along x,
  P1 at x≈-0.55, heads at y≈1.65; the default camera looks from +z). `delete window.__camHold` releases it.
  Several screens in one run: inside CODE `await __shot('tag')` saves `a-tag.jpg`. Menu screens are opened by clicking their buttons
  (`go-fighter`, `go-set`, `go-quick`, …; `go` starts the quick fight). Small / touch screen: append `WxH [touch]`, e.g.
  `bash tools/shot.sh /tmp/shots/s.jpg js "CODE" 740x360 touch` (`390x800 touch` = portrait phone, rotated stage).
  Then open the JPG with the Read tool. Software rendering: ~30 s – 3 min per shot. Compare before/after.
  Menu screens slide in with CSS transitions (real time): append `settle` after `WxH [touch]` (or `SHOT_SETTLE=1`) and every shot
  first waits for them to finish (`settle()` in `tools/shot.py`).

## Smoke set (R-01) — run it before every PR
- `bash tools/shot.sh /tmp/shots/s.jpg smoke` → `tools/test/smoke.py`: runs `docs/audit/scenarios/{menu,fight,modes,phone}.js` at
  1280×720 and 740×360 touch, each in a fresh browser context (~6–7 min). Exit code 1 on any `pageerror` / `console.error`
  (only SwiftShader chatter and the `/favicon.ico` 404 are ignored), a game that does not load, a scenario that throws or times out,
  a state not reached (`NEED`: `fight`, `kd`, `ko`, `replay`, `result`, `talk` — every `G.state` assignment is recorded by a setter)
  or a menu screen that did not open. Prints a table: states in order, the smallest tap target, ms per `__tick` frame; frames are
  `/tmp/shots/s-desk-fight-f4.jpg`, … Narrow it while working: `... smoke --only fight,modes --vp desk`.
- A new scenario: add `docs/audit/scenarios/NAME.js` (one `(async () => { … })()` expression, `await __shot('tag')` for frames,
  returns a log string) and list it in `SCEN` / `NEED` of `smoke.py`.

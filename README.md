# Bare-Knuckle Boxing

**Играть онлайн:** https://evdokimovbusinez-code.github.io/bareknuckle-boxing/

Браузерная игра про кулачный бокс на three.js: физический ragdoll (XPBD) для нокаутов и нокдаунов, кровь, пот, рассечения, повторы с разных ракурсов, карьера из 8 соперников, спарринг в шлемах и перчатках, груша, кастомизация бойца.

## Запуск

Нужен любой статический сервер (из `file://` ассеты не загрузятся):

```bash
python3 -m http.server 8000
# открыть http://localhost:8000/
```

## Управление

**Компьютер**

| Клавиши | Действие |
|---|---|
| D / → | шаг вперёд |
| A / ← | шаг назад |
| W / ↑, S / ↓ | кружить вокруг соперника |
| U / ЛКМ | джеб |
| I / ПКМ | кросс |
| J / K | хук левой / правой |
| N / M | апперкот левой / правой |
| S (↓) + удар | удар в корпус |
| W (↑) + удар | сильный удар (медленнее, дороже по дыханию) |
| Q / E | уклон влево / вправо |
| C | нырок |
| Пробел (держать) | блок |
| Esc | пауза |
| F3 | счётчик производительности |

**Телефон** — стик слева: ходьба, быстрый рывок = уклон. Справа — зона ударов: тап или свайп ↖ = джеб, ↗ / ↑ = кросс,
← / → = хуки, ↙ / ↘ = апперкоты; стик вниз / вверх в момент удара = в корпус / сильный. Кнопка «Блок» — держать.

В первых трёх боях игра подсказывает по одной клавише по ходу боя (блок, когда соперник замахивается; корпус, когда он закрыл голову…);
отключается в «Настройках» → «подсказка клавиш в бою».

В меню «Вид → графика» — разрешение рендера (авто / 720p / 1080p / 1440p).

## Структура

- `index.html` — собранная игра (одна страница, three.js и cannon-es грузятся с jsDelivr)
- `assets/` — модель бойца, анимации ударов, текстуры
- `src/` — исходники: `g_a.js` (рендер), `g_pre.js` (шейдеры кожи, крови, пота), `g_b.js` (игра: бойцы, физика, ИИ, UI), `g_head.html` (разметка и стили), `boxer.html` (базовые блоки: ринг, ткань, волосы)
- `src/assemble.py` — сборка: `python3 src/assemble.py` пишет `index.html` и отладочный `gtest.html`
- `tools/gp.py` — headless-прогоны через Playwright для тестов и бенчмарков

## Бот для задач

- Задачу можно поставить, открыв issue или написав комментарий с `@claude`.
- Бот работает в ветке `claude/issue-N`, сам собирает игру (`tools/check.sh`) и отчитывается в треде.
- Изменения попадают в игру после слияния PR в `main`.
- Модель и бюджет настраиваются в `.github/workflows/claude.yml` (`BOT_MODEL`, `BOT_EFFORT`, `BOT_BUDGET`).

# Bare-Knuckle Boxing

**Играть онлайн:** https://evdokimovbusinez-code.github.io/bareknuckle-boxing/

Браузерная игра про кулачный бокс на three.js: физический ragdoll (XPBD) для нокаутов и нокдаунов, кровь, пот, рассечения, повторы с разных ракурсов, карьера из 8 соперников, спарринг в шлемах и перчатках, груша, кастомизация бойца.

## Запуск

Нужен любой статический сервер (из `file://` ассеты не загрузятся):

```bash
python3 -m http.server 8000
# открыть http://localhost:8000/
```

## Управление

**Компьютер**

| Клавиши | Действие |
|---|---|
| WASD / стрелки | ходьба (A/D — назад/вперёд, W/S — кружить) |
| ЛКМ / J | джеб |
| ПКМ / K | кросс |
| СКМ / O | оверхенд |
| U / I | хуки |
| M / , | апперкоты |
| Shift + удар | в корпус |
| F | следующий удар сильный |
| Q / E | слипы |
| C | нырок |
| X | отклон |
| Пробел (держать) | блок |

**Телефон** — стик слева (рывок = уклон), кнопки ударов справа.

В меню «Вид → графика» — разрешение рендера (авто / 720p / 1080p / 1440p).

## Структура

- `index.html` — собранная игра (одна страница, three.js и cannon-es грузятся с jsDelivr)
- `assets/` — модель бойца, анимации ударов, текстуры
- `src/` — исходники: `g_a.js` (рендер), `g_pre.js` (шейдеры кожи, крови, пота), `g_b.js` (игра: бойцы, физика, ИИ, UI), `g_head.html` (разметка и стили), `boxer.html` (базовые блоки: ринг, ткань, волосы)
- `src/assemble.py` — сборка: `python3 src/assemble.py` пишет `index.html` и отладочный `gtest.html`
- `tools/gp.py` — headless-прогоны через Playwright для тестов и бенчмарков

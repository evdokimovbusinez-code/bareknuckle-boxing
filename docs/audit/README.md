# Снимки и сценарии аудита #58

Выводы — в `docs/SCORECARD.md`, задачи — в `docs/ROADMAP.md`.

## Как повторить

```bash
bash tools/shot.sh /tmp/shots/menu.jpg js "return await eval(await (await fetch('docs/audit/scenarios/menu.js')).text())"
bash tools/shot.sh /tmp/shots/ph.jpg   js "return await eval(await (await fetch('docs/audit/scenarios/phone.js')).text())" 740x360 touch
bash tools/shot.sh /tmp/shots/loc.jpg  js "window.__locs = ['metro']; return await eval(await (await fetch('docs/audit/scenarios/locs.js')).text())"
bash tools/shot.sh /tmp/shots/mp.jpg mp
```

Дымовой набор (R-01): `bash tools/shot.sh /tmp/shots/s.jpg smoke` — `menu`, `fight`, `modes`, `phone` на 1280×720 и 740×360 touch,
код ≠ 0 при ошибке в странице или недостигнутом состоянии (`tools/test/smoke.py`).

Сценарий — одно выражение `(async () => { … })()`; кадры сохраняются как `ИМЯ-метка.jpg`, строка `JS RESULT:` — журнал состояний и замеров.
Бои случайны: кадры от прогона к прогону отличаются.

| Сценарий | Что проходит |
|---|---|
| `scenarios/menu.js` | главное меню, быстрый бой, боец, магазин, соцсети, история, настройки, тренировка, бой с другом |
| `scenarios/fight.js` | стердаун → бой → серия ударов → нокдаун → отсчёт → реванш → нокаут → повтор → итог; время шага симуляции |
| `scenarios/locs.js` | быстрый бой на парковке, шинах, дворе, складе, метро, в баре; время холодного старта, треугольники |
| `scenarios/modes.js` | груша, пауза и настройки из паузы, спарринг, обучение, история «Бар» (диалог, бой, итог), карточка карьеры |
| `scenarios/story.js` | R-17: глава «Бар» — рамка головы говорящего в диалоге (поля в %, верх окна диалога), одежда героя и таймер в бою, образ игрока после главы |
| `scenarios/phone.js` | меню, экраны, бой, пауза, нокаут, итог на телефоне + минимальные цели нажатия |
| `scenarios/perf.js` | `__perf.report` (low / high, 8 площадок), шаг симуляции в бою и на нокауте, оверлей F3 |
